C++ Code Listing

Below is an example of a simple C++ program that prints "Hello, World!" to the console:


        // C++ program to print "Hello, World!"
        #include <iostream>

        int main() {
            // Output message to the console
            std::cout << "Hello, World!" << std::endl;
            return 0;
        }

To compile this program, enter the following command:

g++ hello.cpp -o hello

In this example:

  • std::cout is a standard output stream in C++.
  • << is an operator that inserts data into the output stream.
  • message refers to the string "Hello, World!" that will be printed.
